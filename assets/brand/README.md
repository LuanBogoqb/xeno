# XENO — pacote de identidade

PNGs derivados da referência aprovada, todos raster. O ponto de partida é
`lockup-black-on-white.png`; as outras versões são derivações e podem ter
pequenas diferenças.

- `symbol-*`: símbolo isolado, sem o wordmark.
- `lockup-*`: símbolo empilhado sobre o wordmark XENO.
- `banner-light` / `banner-dark`: composição horizontal 3:1, símbolo à esquerda
  e wordmark à direita, para o topo do repositório.
- `*-black-on-white` / `*-white-on-black`: arte sólida sobre fundo sólido.
- `*-black-transparent` / `*-white-transparent`: arte com canal alfa.

As variantes brancas transparentes são conversões de cor das pretas
transparentes, com só o RGB trocado e o alfa preservado. Elas parecem vazias num
visualizador de fundo branco: use sobre fundo escuro.
