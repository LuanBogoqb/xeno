# AGENTS

Este repositório tem regras próprias de texto, organização e segurança. Leia
[`docs/padroes/README.md`](docs/padroes/README.md) antes de escrever qualquer
arquivo, comentário, documento, mensagem de commit ou texto de pull request.

O resumo, para consulta rápida:

- português do Brasil; identificador, código e citação literal ficam no original;
- o texto não descreve como foi produzido, por quem, nem onde;
- substitua o texto existente; não anexe versão nova nem deixe registro do que
  mudou fora do git;
- arquivo novo tem lugar na estrutura e entra no índice do diretório no mesmo
  commit;
- nada de `dumps/`, chave, perfil ou captura dentro do git.

Antes de commitar, rode os comandos de
[`docs/padroes/checklist.md`](docs/padroes/checklist.md).
